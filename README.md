# Planting Planner
## *Your Digital Garden Companion*
---

**What this application does**

The **Planting Planner** is an application designed to help gardeners document, organize, and manage their plants more efficiently. It allows users to store essential information such as watering frequency or ideal growing conditions all in one place. With everything organized and easily accessible, plant care tasks can be planned easier and gardening practices can be optimized. This application can also allow users to add personal notes for each plant making it much simpler to record observations, gardening tips, or seasonal reflections. 

**Who will use this application**

Anyone that has a passion for gardening would like to use this application. It is useful for those who want to take note of the care tasks for various plants, maintain consistent gardening routines, or track the well-being of plants through organized documentation.

**Why this project is of interest to me**

I’ve always had a love for plants and gardening so my collection has grown immensely over the years, and with it, the challenge of remembering each of their needs, watering schedules, light requirements, etc. There have been times when life gets very busy and this can sometimes visibly reflect the well-being of my plants even though I never want to see them struggle under my care. That is why this project is especially meaningful to me as this tool is a way to bring calm and clarity into something I love deeply. 

Creating **Planting Planner** is a way for me to build a space where I and other users can track, document, and care for plants in a thoughtful and organized way. It is like a digital garden journal that can help support mindful and consistent plant care, even when life gets hectic.

## *User Stories*
- As a user, I want to be able to add a plant to the list of plants and specify it's name, subtype, and category
- As a user, I want to be able to add care information and specific user-written notes to the plant
- As a user, I want to be able to remove a plant from the list of plants
- As a user, I want to be able to view a plant from the list of plants
- As a user, I want to be able to view the plants in the list of plants
- As a user, I want to be able to filter the list of plants by category
- As a user, I want to be able to add and remove the notes for a specified plant
- As a user, I want to be given an option to save my collection of plants to file if I choose to do so
- As a user, I want to be given the option to load my collection of plants when I choose to do so
